# Arithmetic Engine

A standalone browser-based arithmetic expression calculator.

## Features
- Addition, subtraction, multiplication and division
- Powers using `^`
- Modulo using `%`
- Parentheses
- Unary positive/negative numbers
- Calculation history
- No `eval()` or `Function()` execution
- Works as a static GitHub Pages website

## Publish with GitHub Pages

Upload these files to the root of your repository:

- `index.html`
- `LICENSE.txt`
- `README.md`

Then open:

**Repository → Settings → Pages**

Choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Save the settings and GitHub Pages will provide the website URL.
